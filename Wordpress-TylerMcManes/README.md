# WORDPRESS CONGRESSIONAL DIRECTORY

## Technologies Used
- WordPress
- PHP
- MySQL
- HTML, CSS, and JavaScript

## Instructions
- Install XAMPP
    - In the XAMPP Control Panel, start Apache
- Install MySQL Community Edition
    - Select MySQL Community Server
    - Select the MSI Installer
    - Start MySQL through Windows Services
- Configure phpMyAdmin to connect to your MySQL server
- Open phpMyAdmin using localhost/phpmyadmin
    - Create a new database
    - Import both provided SQL files into that database
- Install WordPress using that database
- Install and activate the Code Snippets plugin in WordPress
    - Import and activate the provided JSON snippet
- Install the WordPress Importer plugin and import the XML file
    - Assign the imported content to your existing WordPress user
- Navigate to Pages and view the U.S. Congressional Directory page

## Notes
- Do not rename either of the SQL tables
- Use MySQL 8.0 or newer
- Do not start MySQL in the XAMPP Control Panel
